# utility-scripts-hub
A collection of handy utility scripts and everyday automation tools.

## Astra AI Android app

This repository also contains **Astra AI**, a personal Gemini-powered assistant available as a GitHub Pages web app and an Android APK. The project files are in `site/` and `android/`.

- Website: https://himans111.github.io/utility-scripts-hub/
- Android APK: produced by GitHub Actions and published in GitHub Releases.
- In-app **Check updates**: checks both website assets and the latest Android APK release. Android always asks the user to confirm APK installation.
- Gemini key: enter it inside the app Settings; it is not stored in this repository. Do not commit API keys.

See [ANDROID-BUILD.md](ANDROID-BUILD.md) for build, update, signing and API-key notes.
